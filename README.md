# Study Tasks — a GroundTruth demo repository

A tiny beginner project: add a study task, list it, and mark it complete.
No frameworks, dependencies, accounts, API keys or external services.

## Run locally

Requires Node.js 22.13 or newer (Node's SQLite module may print an experimental warning).

```sh
npm test
npm start
```

Open http://127.0.0.1:8090. SQLite data stays in `.data/tasks.sqlite` (ignored by Git).
Stop with Ctrl+C. GroundTruth only needs the public source; this app does not need to run during the pitch.

## Understand the code

```text
Browser form → POST /api/tasks → validate title → SQLite INSERT
Browser list ← GET /api/tasks ← SQLite SELECT
Complete button → POST /api/tasks/:id/complete → SQLite UPDATE
```

| Area | Start here | Beginner concepts |
| --- | --- | --- |
| Backend | server/api.js, server/validation.js | requests, routes, trim, validation, status codes |
| Data | db/schema.sql, db/store.js | rows, primary key, defaults, parameterized queries |
| Frontend | frontend/index.html, frontend/app.js | form events, fetch, DOM, safe text rendering |
| Testing | tests/tasks.test.js | arrange/act/assert, invalid input, state changes |

## Use with GroundTruth

Paste this repository's GitHub URL into GroundTruth. Pick Backend first and a goal such as:
“I am a complete beginner. Help me understand how adding a task works. Use simple MCQs and small coding tasks.”
Read the overview and visual before practice. For a follow-up, choose Data to learn how task records are stored.
Question wording and suggested answers are generated by your local model; verify them against the source.

This is deliberately a local teaching example. It has no login or multi-user isolation and is not intended as a deployed task service. There are no intentionally broken security controls or planted failures.
